
# 📊 HR Analytics Dashboard

An interactive **HR Analytics Dashboard** built using **Python, Streamlit, Pandas, and Data Visualization** to analyze employee data and generate meaningful HR insights.

The dashboard helps understand employee demographics, departmental distribution, attrition patterns, and other key workforce metrics through an interactive and easy-to-use interface.

---

## 🚀 Project Overview

This project focuses on analyzing HR data to identify important workforce trends and patterns.

The dashboard transforms raw employee data into meaningful visual insights, helping users understand employee distribution, attrition, departments, and other HR-related metrics.

---

## ✨ Key Features

* 📌 Interactive HR Analytics Dashboard
* 👥 Employee overview and workforce analysis
* 🏢 Department-wise employee analysis

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Task_3_HR_Analytics.git
```

### 2. Navigate to the Project Folder

```bash
cd Task_3_HR_Analytics
```

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit Dashboard

```bash
streamlit run dashboard/app.py
```

The dashboard will open in your browser.
